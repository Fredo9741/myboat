# MyBoat - Site de vente de bateaux

Ce projet est une réplique du site web MyBoat, une plateforme de vente de bateaux dans l'océan Indien.

## Structure du projet

```
myboat/
├── assets/
│   └── images/         # Images et icônes du site
├── css/
│   └── main.css        # Styles CSS principaux
├── js/
│   └── main.js         # Scripts JavaScript
├── index.html          # Page d'accueil
└── README.md           # Documentation du projet
```

## Technologies utilisées

- HTML5
- CSS3 (avec variables CSS)
- JavaScript (vanilla)
- Bootstrap 3.3.7
- jQuery 3.6.0
- Font Awesome 5.15.4

## Fonctionnalités

- Design responsive
- Menu de navigation avec dropdowns
- Menu hamburger pour mobile
- Animations de scroll
- Intégration des réseaux sociaux
- Catalogue de bateaux
- Système de recherche

## Installation

1. Clonez le repository
2. Ouvrez `index.html` dans votre navigateur
3. Pour le développement, utilisez un serveur local (par exemple, Live Server de VS Code)
